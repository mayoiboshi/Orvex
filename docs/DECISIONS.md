# 技术决策记录

本轮依据实际代码整理。下列“采用”表示已在仓库落实；理由说明现阶段收益和限制，不把旧提议写成已验证事实。架构细节以 [ARCHITECTURE](ARCHITECTURE.md) 为准。

## 已采用

| 编号 | 决策与依据 | 当前理由 | 限制 / 何时重新讨论 |

| D01 | Flutter/Dart，单仓库、单应用；四个平台宿主目录 | 复用当前界面和播放会话代码，保持交付简单 | 当前验收以 iOS/iPadOS 为主，不推导出四平台完成 |

| D05 | PlaybackSession 管会话代次、串行命令和订阅生命周期 | 防止切片/快速切换时旧事件污染新状态；可用假引擎测试 | 测试不替代真实解码、音频和长时间稳定性检查 |
| D06 | 移动端复制导入，视频和字幕按完整内容哈希复用已有路径 | 系统选择器地址不宜长期保留；相同内容不再新增副本，旧进度身份保持 | 同名不同内容保留；既有重复副本不自动删除，无空间预检；首次校验旧文件需读取内容 |
| D07 | 已导入媒体使用相对位置作为稳定身份；历史/进度采用 v2 并保留 v1 | 已修复 iOS 更新后绝对路径失效、历史重复；能按最近观看状态恢复 | 旧数据异常、多个更新周期仍需覆盖；身份逻辑涉及媒体、历史、续播和元数据多处 |
| D08 | 小量进度/历史/设置用 SharedPreferences；元数据和封面用文件缓存 | 满足当前行为，避免现在就引入数据库及生成工具 | 没有数据库事务、容量淘汰和完整缓存修复入口；规模增长后评估，不预先选库 |
| D09 | Bangumi 公共 API，自动关联返回候选首项 + 整组人工更正 + 本地缓存 | 用户明确要求默认选择第一项；同一规范化片名共享请求，人工选择不被后台覆盖 | 首项不保证语义正确，可手动更正或忽略；未匹配不妨碍浏览/播放。旧严格判定辅助函数保留，但不再作为自动关联门槛 |
| D10 | iOS 音频会话使用小型原生通道，系统中断只暂停 | 避免返回前台或重复中断导致意外自动播放 | 真实来电、耳机断开等系统事件尚需真机复验；后台连续播放不是当前行为 |
| D11 | 三项本地基础检查，通过 scripts/check 组合 | 一条命令复现格式、分析、普通测试，不加重型工具链 | 不包含设备测试、真实 API 或平台构建；检查失败不能靠排除规则绕过 |
| D12 | S/M/L 分级；S/M 简短方案或直接做，L 一次设计确认 | 保留快速试验效率，只为真正高风险变更加约束 | 不要求 S/M 设计文档、独立 Reviewer 或多阶段审批；已授权工作不重复确认 |
| D13 | 控制层沿用现有播放会话；iOS 亮度采用独立小型原生通道，无新增依赖 | 复用音量/速度/跳转接口，显示亮度不混入播放引擎；临时倍速和拖动状态随当前视图清理 | 亮度在退出/失活时恢复原值，模拟器及其他不支持平台明确降级；iPhone 本轮整体操作已获用户通过反馈，亮度恢复与真实系统事件仍待单独验收，Android 亮度适配未实现 |
| D14 | 中性色/冷蓝语义 Token + ThemeExtension，System/Light/Dark 持久化；共享 Flutter GlassSurface | 统一现有页面并保留播放逻辑，不增加 UI 依赖；限制模糊范围，系统/应用减少透明度时实色降级 | 是 Flutter 玻璃风格，不是原生 Liquid Glass，没有真实折射。原生视图融合待调研；新视觉未获物理 iPhone/iPad 验收，详见 DESIGN_SYSTEM 与视觉验证 |

## 局部页面返回（2026-11-06）

采用 Flutter 自带的 Navigator / CupertinoPage / MaterialPage 和 NavigatorPopHandler，为播放、分集与独立目录浏览补充真实返回历史。复用 iOS 交互式边缘返回，Android 保留系统分发，桌面增加快捷键/鼠标返回；不是 UIKit 原生桥接，不新增路由包或全局导航框架。标签仍同级切换，媒体/存储/播放会话边界不变。确认退出才暂停，取消返回不影响播放，全屏保留播放手势。实现、证据与平台限制见 [返回验证](verification/back-navigation/README.md)。

## 本地字幕记忆与匹配（2026-11-06）

按稳定视频身份保存手动外挂、关闭或内置轨道选择，优先于自动匹配。新增独立偏好键，无历史/索引迁移；字幕引用使用 Imports 相对位置或授权根 ID + 相对路径。目录视频只查同一层，单文件导入查已有 App 字幕；完整名称、语言后缀归一、集数依次降级，最高级多候选交给用户。不把未授权的 iOS 原文件夹写成可扫描。复用原会话命令/代次和授权管理，mpv 的 sub-auto 关闭以避免绕过用户策略，libass/解码不变。证据与边界见 [字幕验证](verification/subtitle-memory/README.md)。

## 字幕延迟与文字样式（2026-11-10）

字幕设置由 PlaybackSession 按会话代次串行传给现有 MediaKitEngine/libmpv，偏好使用独立键 `orvex.player.subtitleStyle.v1`，缺失字段采用默认值，不迁移既有字幕选择。默认保留引擎的 ASS 覆盖模式；用户可选择强制覆盖，但可能改变原排版或特效。字幕缩放本身也可能影响 ASS，位置和样式效果需按文件验证。图像字幕和画面烧录字幕不支持文字样式；字幕独立亮度及背景框尚未实现。验证范围见 [验证状态](verification/STATUS.md#字幕延迟与文字样式2026-11-10)。

## 2026-11-06：只读文件夹来源与轻量播放列表

- 在既有 LocalMedia/PlaybackSession 上增加可选目录身份、资源准备/释放回调和列表；不建立第二套媒体/进度/播放器状态。
- Apple 采用原生目录选择与书签，Android 采用 SAF，Windows 复用文件选择依赖。原文件只读，旧单文件导入副本保留；没有新增包。
- 新目录索引用应用私有 JSON 原子替换及备份，不迁移既有 Imports、历史 v2 或 Bangumi 旧条目键；目录元数据采用稳定媒体身份。只有可靠系统身份才关联移动/重命名。
- Apple AVAssetImageGenerator / Android MediaMetadataRetriever 后台生成预览，与 libmpv 播放分离；原生提取不支持时使用占位，不另开大量播放器。Windows 提取、外部文件提供方覆盖和真实 MKV 缩略图兼容仍待验证。
- 自动下一集默认关闭，仅明确开启且播放页前台生效。分组浏览不切换播放内容。详见 [实现边界](folder-library.md) 和 [验证记录](verification/folder-library/README.md)。

## 2026-11-06：名称剧集分组与默认首项关联

- 用文件名片名、集数、季和年份派生展示分组，分来源保留；仅有集数时尝试真实上级目录名及季目录。分组不修改原文件、文件身份或进度键，不持久化第二套媒体实体。
- 媒体库默认剧集浏览，原目录浏览保留；从剧集打开视频采用该组排序后的播放列表，跨范围目录连续观看。匹配失败也保留可见分组。
- 按用户要求以客户端返回候选首项自动关联，替代旧的置信门槛；人工更正批量作用于整组，后续发现的同组成员继承已有人工选择。旧人工和已匹配记录保留，旧待确认候选可离线采用首项；缓存字段仍兼容原格式，规则版本为 3。
- Apple 原生预览解码不支持时，复用已有 media_kit/libmpv 的独立短时输出；只在原单任务队列内执行，关闭音轨/字幕，不进入播放会话或写进度，不引入新依赖。权限拒绝不绕过。真实 MKV 和物理 iPad 证据见 [预览补充](verification/mkv-preview/README.md)。
- Apple 原生提帧使用独立串行队列，保留单任务解码上限。目录队列负责句柄登记和失效，已接收的提帧任务在实际读取期间持有原安全作用域，避免提帧等待占住选集和授权操作。
