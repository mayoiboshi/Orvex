## 本轮工程基线

- 统一协作规范与 S/M/L 处理方式，整理 ARCHITECTURE、DECISIONS、ROADMAP；不改业务代码。
- 增加 `scripts/check`，仅组合项目本地格式检查、静态分析和普通测试。本轮三项通过，47 项测试通过。
- 沿用原有 SDK、依赖及 Flutter lints，没有新架构框架、CI、Reviewer 或审批链。
- 审计起点为没有提交的本地仓库；用户随后明确授权向指定个人远端提交和推送本轮基线。提交结果以 Git 历史和最终汇报为准，不把此授权扩展为以后任务的默认推送权限。

## 后续候选，不是已承诺功能

- iOS/iPadOS：外挂字幕选择恢复、文件副本整理、番剧与季度聚合、分集展示；按需求选择小任务，涉及跨模块数据设计时走 L。
- 平台恢复：先准备对应宿主和 SDK，核验 Android 发布网络/签名及 macOS 联网授权，再做最小构建与真实播放；Windows 需要 Windows 开发主机。本轮不安装 Android SDK、不更改原生权限或签名。
- 媒体源和系统能力：NAS/云盘、媒体下载、画中画、投屏等，先明确用户要解决的场景，再按 L 设计；不提前搭插件或任务调度框架。
- 持久化：只有真实容量、查询和迁移需求超过当前实现时再评估数据库；Drift/SQLite 是候选，不是已实施或已确认选择。
- 分发：明确项目许可证与第三方来源清单，区分测试素材和正式资源，补构建/签名说明。自动发布和复杂 CI 暂无必要。
