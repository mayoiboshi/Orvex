# Orvex 2.0 初版验证状态

更新日期：2026-11-06。当前交付优先 iOS/iPadOS。iPhone 核心播放、Bangumi 柯南个案和历史路径修复已有用户反馈；其余平台与场景按下文区分。本文件保留验证历史，当前能力清单统一见 [ROADMAP](../ROADMAP.md)。

## 已有证据

- Flutter 3.47.9 / Dart 3.13.7、Xcode 27.2、CocoaPods 1.17.0 可用。
- 独立 Java 17.0.21 已安装；系统默认 Java 8 未改变。
- 当前 47 项单元/界面测试通过，静态分析无问题；包括四模块导航、搜索、Bangumi 关联和缓存、长集数匹配，以及历史跨容器重定位、去重和最近进度迁移。
- 用户报告两条 615 集记录且一条播放失败。读取 Orvex 自身历史与导入文件信息，确认只有一份视频，旧记录仅容器 UUID 不同。已改为稳定的相对导入身份，历史 v2 重定位并合并同一副本、进度 v2 保留最近状态；原 v1 偏好仍可恢复。47 项测试及模拟器原生回归通过。覆盖安装后设备偏好确认只剩一条有效记录，用户回复“只有一条，播放和续播正常”，本次真机修复验收 Passed。
- 用户截图暴露 `Detective Conan 0615` 四位集数未被剥离，且英文别名未收录于 TV 正篇，导致待确认结果以剧场版为主。已针对截图文件名在 iPhone 模拟器真实联网复验：自动匹配 TV 正篇 899、第 615 集、封面、旧待确认缓存迁移与离线恢复均通过。未使用用户原视频或在真机导入生成素材。
- 此修复的正式入口 Release 已通过签名校验，覆盖安装并在用户 iPhone 启动；正式包没有测试代理或模拟器实验参数。2026-11-05 用户针对“名侦探柯南 · 第 615 集”及正确封面的复验问题回复“已正确显示番剧名和封面”，该原文件案例记为 Passed（用户真机实测）。
- Bangumi 接入已在 iPhone 与 iPad 模拟器中通过真实 API 验证：文件名自动关联条目 400602，真实封面解码、资料面板、离线恢复资料与封面均通过；不等同于物理设备网络或一般识别准确率验收。
- Bangumi 接入后的 iPhone 模拟器原生播放回归通过，模拟器声音仍为 Not Tested。
- Bangumi 版本正式入口 Release 构建及签名校验通过，已覆盖安装并成功启动于用户 iPhone。未卸载或主动删除用户媒体；正式包无模拟器无声或测试代理参数。后续真机个案反馈见上述柯南回归。
- 新版底部四模块：首页、媒体库、播放记录、设置；首页使用实际本地媒体和实际播放记录。iPhone/iPad 布局测试覆盖 360、430、744、1194 宽度，iPhone 与 iPad 模拟器首页预览已检查。

- macOS Release 和未签名 iOS 设备 Release 构建成功。
