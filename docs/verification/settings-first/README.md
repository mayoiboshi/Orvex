# 设置页第一轮整理

页头复用媒体库的 `libraryBrowseInset`。表单在宽窗口保留原有最大宽度并水平居中，在窄窗口占满页边距内的宽度。页底继续采用底部播放卡和导航测量后的留位。

| 设置 | 存储与实际作用 |
| --- | --- |
| 主题 | `orvex.appearance.theme.v1` 保存系统、浅色或深色。系统模式随平台外观变化。 |
| 减少透明效果 | `orvex.appearance.reduce-transparency.v1` 保存应用自己的选择。iOS 和 macOS 原生桥接仍读取系统要求，两者任一开启时使用不透明玻璃面并停止相关模糊，例如播放控制层。 |
| 显示继续观看 | `orvex.home.continue.v1` 影响首页的续播区展示，保留播放历史和进度。 |
| 自动匹配番剧 | 复用 Bangumi 本地资料索引的开关。查询使用整理后的片名，关闭时清除排队工作并保留已匹配资料。手动搜索和更正仍在资料页可用。 |
| 版本与开源许可 | 应用版本来自已安装包。直接使用锁文件中已有的 `package_info_plus` 版本，许可页仍使用 Flutter 的许可列表。 |

设置主列表移除了导入动作、外挂字幕说明和自动保存进度说明。字幕选择、匹配和记忆仍可从播放器操作，播放进度仍按现有检查点保存。

`./scripts/check` 通过，包含格式、静态分析和 171 项测试。主题保存后重新初始化偏好控制器，核对三种选择的读回结果；组件测试模拟系统外观与 iOS 辅助功能变化，并用替身验证 Bangumi 自动查询。正式版已覆盖安装并启动于 iPad Pro 2022。真机的应用重启、系统辅助功能切换和用户片库操作留待人工验收。

iPad 模拟器集成测试通过。核对媒体库与设置页的页头左边界、宽屏表单居中、窄窗口表单边距、主题菜单、真实版本号、隐藏续播区后保留原记录与播放会话，以及有底部播放卡时仍能在窄窗打开开源许可。该测试使用无声模拟器素材。
