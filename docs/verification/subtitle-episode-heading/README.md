# 数字开头字幕集号识别修复

日期：2026-11-06。

## 原因与修改

iPad 615 集为已授权目录中的 `[Fabre-RAW] Detective Conan 0615 [NetflixJP] [1080p].mkv`。用户提供对应字幕名为 `615集 日志奏出的秘密（下集）.ass`。

视频的 `0615` 可以解析；字幕以“数字 + 集”开头，没有“第”，此前规则没有识别到集数，因此没有候选可以自动选中。只读查看 Orvex 自身索引和相关偏好时，615 的索引可用，没有该集手动/关闭记忆，自动匹配处于默认开启状态。没有读取外部字幕目录或视频/字幕内容；真实文件名由用户确认，诊断边界见 [diagnosis.json](diagnosis.json)。

只在字幕名称匹配器补上 `615集`、`0615 话`、`615話` 等开头。完整名称仍优先于集数；相邻集、不同季与多候选仍按原规则处理。媒体分组、Bangumi、播放器内核、存储键与索引格式不变，无数据迁移；已有手选或关闭记忆继续优先，不批量清除用户选择。

## 验证

- 修复前，以完整视频名和字幕名运行回归测试，实际得到“不匹配”，见 [失败复现](regression-before.log)。
- `./scripts/check` 通过：格式、静态分析、131 项测试，见 [检查输出](check.log)。覆盖实际 608/609/615 名称、前导零、话/話、邻集/长数字、全名优先及多候选不猜选。
- iPhone 和 iPad 模拟器均通过原生 remember / restore 两个独立进程。授权目录中 `第10集.mp4` 自动选择 `10集 数字集号解析验证.srt`，字幕开关前后原生画面底部像素变化 4100；手动 SRT 和关闭记忆跨重启恢复，容器路径实际变化，授权全部释放。见 [iPhone 首次进程](iphone-remember-results.json)、[iPhone 重启进程](iphone-restore-results.json)、[iPad 首次进程](ipad-remember-results.json)、[iPad 重启进程](ipad-restore-results.json)。

- iPad 早期运行两次停在设置页等待全局画面停止刷新，第一次中断后的 restore 因缺少手动选择前置条件也失败，保留相应 `first-attempt` / `second-attempt` 日志。将等待限制为 10 秒后，明确得到 [pumpAndSettle 超时](ipad-settle-timeout.log)。原生视频纹理可能在暂停后继续安排帧，不适合用全局“无新帧”判断界面就绪；测试改为有限界面转场等待及具体字幕状态断言，所有匹配、渲染像素、重启和授权释放断言保留，随后两个阶段均通过。未关闭检查或修改产品逻辑绕过失败。

所有生成样片实验都在明确标识的模拟器内执行；声音、用户真实 615 集字幕渲染和 Android/macOS/Windows 本轮为 Not Tested。设备安装成功不等于实际字幕验收。

## 真机下发

沿用现有个人团队和 bundle ID，正式 `lib/main.dart` Release 已构建；签名验证、两台设备描述文件、iPhone/iPad 设备族及无测试/代理参数检查通过，见 [构建核对](build-verification.json)。已在 iPhone 17 Pro Max 和 iPad Pro 2022 覆盖安装成功；iPad 启动成功，iPhone 因锁屏被系统拒绝启动，解锁后可自行打开，见 [安装摘要](device-install-launch.json)。没有卸载、清空数据或导入生成样片。

重新打开 615 集会按新规则扫描同目录字幕；如果存在用户保存的手动或关闭选择，仍优先恢复该选择，可在播放设置中主动恢复自动匹配。真实 615 集自动显示字幕仍待用户确认。
