# 播放器主控制层第一轮精修

2026-11-09。视频和外挂字幕仍经 media_kit / libmpv / libass 渲染到同一纹理。Flutter 控制层原先在底部与下方台词叠放。现将标题、进度和选项放在安全区内的同一顶部浮层。中央播放及前后跳转使用独立底衬，较矮的视口将三个按钮收进顶部操作区。窄屏的音轨和字幕仍可从播放设置打开。进度拖动时显示目标位置，松手后交由现有播放会话跳转。

## 截图

## 验证范围

- `./scripts/check` 通过格式、静态分析和 196 项测试。控件测试覆盖后台、缓冲、锁定、播放手势、指针取消、菜单、键盘焦点和辅助导航。整页测试还覆盖返回剧集列表和从底部播放条恢复。
- `integration_test/player_controls_refine_test.dart` 在 iPad 模拟器使用无声播放，验证字幕确实改变原生渲染帧、控制层显隐前后同一暂停帧一致、拖动生效且保持暂停、播放后自动隐藏、窄窗切换保持会话与轨道。640 × 360 的样片在较高横屏视口内等比完整显示，上下留黑不随控制层变化。
- 截图原片未取得，无法区分其源片黑边与适配留黑，也无法确认字幕类型。该片源、位图和烧录字幕、真机声音、系统分屏及其他平台本轮未做播放验收。顶部或特殊定位字幕仍可能与控件重叠，当前渲染接口没有字幕边界信息。
