## 《超辉夜姬！》分类核验

直接查询 Bangumi 条目接口，条目 604826 返回 `type=2`、`platform=WEB`、`eps=1` 和 `total_episodes=1`。`type=2` 表示动画，`WEB` 表示发行形式。接口另有社区标签「剧场版」「电影」，当前元数据模型不将这些标签作为媒体类别字段。现有字段不足以按项目规则把该条目可靠归为电影或剧集，所以保留「类型未分类」。[Bangumi 条目](https://bgm.tv/subject/604826)

## 验证

- `./scripts/check` 通过格式、静态分析和 153 项测试。
- iPad 模拟器集成测试通过。资料按钮至少 44 × 44 点。点单文件和剧集卡片的资料按钮只打开资料面板，未启动播放或进入剧集列表。长标题实际渲染为两行，收录数量与同行单行标题卡片对齐。单话 WEB 样片在「全部」与「类型未分类」均可访问。
- 首页回归测试覆盖资料入口、海报、导航与续播。真机海报可读性仍待人工验收。
