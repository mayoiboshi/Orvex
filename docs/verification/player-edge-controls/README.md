# 播放器贴边控制层

2026-11-09。撤销上一版的顶部大面板。全屏使用轻量标题行、右侧锁定和两层底栏，内嵌使用紧凑底栏并复用外层返回入口。小窗口把次要操作收进播放设置，内嵌的前后跳转也可由此操作。上、下衬底是随控件显隐的渐变。

本轮保留 media_kit / libmpv / libass 的播放和字幕路径。显示时，边缘渐变或控件可能与贴边字幕重叠。隐藏控件不改变视频位置、画面适配、字幕位置或样式，暂停时手动隐藏不恢复播放。

## 同一暂停帧对照

iPadOS 27.2 模拟器，横屏控制层使用 1194 × 834 逻辑像素视口，内嵌对照为 760 × 428。测试视频为 640 × 360，上下含定位 ASS 字幕，下方为双语。

## 验证范围

- `./scripts/check` 通过格式、静态分析及 196 项测试。覆盖拖动取消与过期回调、保持暂停、锁定与解锁、菜单与焦点、手势和辅助导航。
- iPad 模拟器使用原生无声播放验证 16:9、4:3 和约 2.35:1 解码，核对同一暂停帧和视口在控制层显隐前后保持一致。也验证了单行 SRT、上下定位 ASS、外挂字幕切换，以及切换内嵌／全屏布局后保留同一引擎、文件、位置和所选音轨。
- 对比图的画面中央像素一致，显示时边缘渐变可能压暗下方字幕。用户原片、真机播放及声音、真实系统分屏和非 iOS 平台未验收。
- 整页原生回归首次在切换标签阶段收到了 Flutter 重复组件键错误。旧提交 `0f163ca` 对照运行通过，新版单独复测也通过，并分别检查了进入全屏、退出全屏和关闭后重开。该错误本轮未稳定复现，原因尚未确认。
