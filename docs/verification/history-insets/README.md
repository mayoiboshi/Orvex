# 播放记录页外边距对齐

播放记录页直接复用媒体库作品视图的 `libraryBrowseInset`。该规则根据实际可用宽度计算并用现有间距值约束范围。同一外边距传给标题、空状态和列表的两段滚动布局。

横屏旧版内容外沿距两侧各 36 点。新版与媒体库一致，各 48 点。窄视口与竖屏使用同一个响应式规则。

格式、静态分析和 159 项测试通过，含放大文字时的空状态边界。iPad 模拟器集成测试在 1210 × 834、834 × 1210 与 438 × 834 三种视口测量两页的品牌、标题、内容边界和底部浮层，核对记录数右对齐，回归窄窗末行按钮及无声续播。视口尺寸由测试切换，真机系统旋转和分屏本轮未测。
