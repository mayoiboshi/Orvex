# 播放记录页第一轮验证

每个视频按现有稳定标识保留最近一次播放检查点。位置、时长和完成状态来自播放帧，最近播放时间来自保存检查点时的 UTC 时间，显示时转为设备本地时间并使用应用的时间格式。有效时间仍由存储层倒序排列，缺失或无效的旧时间排在后面。旧记录缺时长时保留实际位置，省略总时长与比例轨道。

记录行复用底部播放卡所用的本地视频预览和同一磁盘缓存。缓存不可用时，作品海报等比完整显示，缺海报时使用文件占位。滑动和重建不会新建提帧流程。浏览与打开资料不会写入播放检查点。

格式、静态分析和 159 项测试通过。组件及存储测试验证真正空状态、缺缩略图和时长、时间缺失、长标题、行与按钮的独立触发及旧记录兼容。iPad 模拟器集成测试确认独立预览文件、真实比例轨道、深浅主题、窄窗末行、指定视频从保存位置续播，以及与底部播放卡标题一致。模拟器播放采用无声模式。
