# 首页最近添加封面

iPad 模拟器使用隔离的测试视频和缓存海报。彩条是生成样片提取出的真实帧。电影测试条目复用了已有缓存图片，只用来验证作品海报尺寸、缓存损坏和回退路径。

[横屏混排](landscape-light-library.png) · [深色滚动到底](landscape-dark-bottom.png) · [窄窗口底部](narrow-light-bottom.png) · [布局和检查结果](observations.json)

- `./scripts/check` 通过格式、静态分析和 140 项测试。首页组件测试覆盖明暗主题、360–1210 点视口、双倍文字、滚动和资料入口。
- iPad 模拟器验证同一作品的不同单集读取不同缓存路径、普通本地视频显示帧、剧场版海报保留 2:3、坏海报回退到帧、混排容器统一 4:3、时长和最后一行可点。续播、媒体库入口和 Tab 导航通过。
- 截图使用 1210 × 834 与 438 × 834 应用视口。真实系统分屏、长时间滚动性能和用户实际片源未验收。
