`./scripts/check` 通过格式、静态分析和 153 项测试。新增用例覆盖组内最新导入时间、缺失值排序、按稳定关联确认类型、同组资料冲突、筛选加搜索、真实字节进度和重复导入。模拟器集成测试另验证排序写入偏好、筛选重置、网格与列表切换、进入作品详情后返回、窄窗最后一项位于底栏上方，以及原有续播和切集。
