截图来自运行中的 iPad 模拟器。电影卡使用测试资料和缓存封面，彩条来自样片。截图中的两部剧集和单文件电影展示相同的年份、评分层级，多集作品另显示实际收录数。

格式检查、静态分析和 148 项测试通过。首页集成测试覆盖宽窄视口和浅深色模式，验证底栏在海报上方使用实色背景，滚到底时最后一排可见且可点击。测试还实际打开了资料、作品详情和续播入口。
