# 播放偏好

设置页保留原来的全宽布局。「播放」和「字幕与音轨」沿用既有分组样式。默认行为与旧版一致。配置通过 `SharedPreferencesAsync` 读写，原来的自动下一集键继续有效。

| 设置 | 应用范围 |
| --- | --- |
| 重新打开视频 | 普通打开支持直接续播、有进度时询问、从头开始。明确的「继续播放」继续用续播位置，「重新播放」从头开始。播放记录与进度保存机制不变。 |
| 默认播放速度、默认画面适配 | 在新会话应用。临时倍速和画面适配不改全局值。填满使用等比裁切。 |
| 自动播放下一集 | 仅在播放器可见且队列中能确认相邻剧集时生效。目标集号重复、同季缺集、作品归属不符时停止；已确认的同作品队列可进入紧接的下一季第一集。手动上一集、下一集继续沿用队列。 |
| 操作与手势 | 步长用于播放器跳转按钮、方向键和移动端双击。移动端可关闭触屏播放手势，单击显示控件仍可用。桌面继续支持双击全屏。 |
| 字幕偏好 | 仍有效的手动字幕和关闭选择优先。配置语言时，按真实内嵌轨道标签选择；找不到语言时，保留既有的本地字幕匹配和文件默认规则。 |
| 音轨偏好 | 根据真实语言标签匹配，找不到时保留文件默认。当前会话的手选不会被后续轨道事件覆盖。应用未持久保存每个媒体的音轨选择。 |

字幕继续走原生 libass，保留原样排版。字幕样式没有配置入口。现有播放器也没有字幕延迟入口。

格式、静态分析和 180 项测试覆盖偏好保存与读回、普通打开和明确续播、临时设置隔离、自动下一集、真实语言标签匹配、缺失标签回退及手选优先。iPad 模拟器使用无声实验模式，以带 eng/jpn 音轨和 eng/zho 字幕的 MP4 验证了默认值和临时调整对原生会话生效。样片由 FFmpeg 标注后只复制到模拟器临时目录，通过 `ORVEX_TAGGED_PLAYBACK_TEST` 启用相关断言。实际音频、物理设备播放和其他平台本轮未测。
