截图来自 iPad 模拟器上的实际应用，宽窗口为 1210 × 834，窄窗口为 438 × 834 应用视口。测试片源与作品资料来自隔离的测试数据，彩条为样片视频帧。模拟器通过原生无声续播及资料、导航入口的检查。系统旋转、分屏、台前调度及播放声音待验收。

`./scripts/check` 通过格式检查、静态分析和 144 项测试。测试覆盖跨季同作品 ID、同名不同 ID、独立电影、普通文件、资料不足和自动匹配存在歧义的情况，以及新增文件排序和从作品进入播放后返回的路径。

正式版已覆盖安装并启动于 iPad Pro 2022。用户片库内的实际聚合和播放效果待真机验收。
