# 媒体库第三轮局部验证

文件夹根页分开显示媒体来源和独立导入。来源数字来自该来源中已索引且可用的视频，进入目录后仅统计当前层的视频。独立导入区域为空时，已有来源仍能直接浏览。加载、读取问题和当前搜索或筛选的空结果各自保留对应提示。

「仅未播放」依据现有播放记录。新打开的子目录继承开关，返回时保留父级自己的开关和搜索。当前层的数量随条件更新，来源总数保持其原有统计范围。

`./scripts/check` 通过格式、静态分析和 156 项测试。组件测试在浅色和深色模式分别使用含 41 个视频的来源，覆盖根页、真空库、读取状态、组合空结果、子目录筛选、清除条件和点击视频。
