# 大屏播放页 UI 精修

日期：2026-11-06。基于现有 PlayerPage / FolderBrowser / PlaybackSurface 继续小幅精修，双栏、播放会话、引擎、字幕和存储方案不变。

## 完成的界面改动

- 顶栏从来源名称优先改为作品上下文优先：已关联作品名或现有剧集名称居上，来源居下；原始文件名继续在文件详情中可读。返回、更多、帮助、添加均保留实际动作。
- 视频维持左贴边、原比例与已有高度约束。只在视频内为悬浮控制留间距；不恢复外侧边距或圆角卡片。三处控制层复用较轻的 Flutter 玻璃底层和边界，中央按键略收紧；减少透明度/高对比度仍实色回退。这不是 Apple 原生 Liquid Glass，没有增加模糊区域或持续动效。
- 新增纯展示组件 WatchInformation：左侧作品名、集号/进度和 Bangumi 次级按钮，右侧前后集操作组及自动下一集文字/开关。窄屏或大文字上下排布。所有命令和偏好写入继续由 PlayerPage 负责，旧偏好键保留。
- 右侧列表宽度微调至 336–392 点；16:9 缩略图约占行宽 35%，限制 116–156 点，观看行基础高度 120 点并随字体缩放。标题、时长/大小、观看状态分行；当前项以 3 点强调条、柔和背景、静态播放标记和选中语义表示，不只依赖文字变色。既有惰性行和缩略图缓存保留，列表没有模糊。
- 右侧工具栏固定，目录/剧集、搜索、当前定位仍可用。中途打开搜索会滚到输入框；列表滚动不带动左侧视频。上下布局仍整体滚动。hover/focus/pressed 沿用 Material 交互并使用语义颜色；动画尊重减少动态设置。

## 实际验证

- `./scripts/check` 全部通过：格式、静态分析、133 项测试，见 [检查日志](check.log)。包含现有播放/字幕/导航回归、1000 行惰性列表及 1.7 倍文字测试；新增信息区在 360/800 点、明暗主题、1/2.5 倍文字时，所有操作仍可点击且无布局异常。
- 初轮有三个界面测试失败：较高行距使固定 100000 点滚动不足以回到第 0 行；信息区可点击区域变化后，单次移动事件仅启动边缘返回而未产生后续位移。测试改为按实际位置回顶和连续跨越手势阈值后移动；保留目录切换、惰性构建、跟手位移、取消不暂停、确认返回等原断言，未删除测试或修改返回逻辑来绕过问题。
- iPad iOS 27.2 模拟器原生 libmpv 验证通过，见 [日志](ipad-native.log)、[结果](ipad-observations.json)。真实打开 Bangumi 面板、开关自动下一集并核对原偏好键、右侧搜索回顶/定位/选集、上一集/下一集均通过。实验偏好隔离在内存，本轮未新增自动开关的原生存储跨重启验证；Bangumi 验证限于打开入口，没有新增 API 联网刮削实验。布局/全屏往返时引擎数维持 1、外挂字幕轨道保持；播放中切换后进度继续推进。实际选集及前后集操作才创建后续会话引擎。
- iPad 截图覆盖竖向原视口、1210×834 横向、600×480 回退、明暗主题和全屏。视频左边界持续为 0；“减少透明效果”开启后无 BackdropFilter。横向与小窗口仍是 Flutter 视口适配，不能等同系统级 Split View、Stage Manager 或物理旋转验收。
- iPhone iOS 27.2 模拟器回归通过，见 [日志](iphone-native.log)、[结果](iphone-observations.json)：明暗、横向窄窗口、全屏和原生播放/外挂字幕状态保持正常，没有宽屏入口。
- macOS 正式入口 Debug 构建通过，见 [构建日志](macos-build.log)；没有用生成媒体在物理 Mac 上做播放实验，桌面键鼠及窗口运行效果未在本轮新增原生验收。
- 所有生成媒体实验在写入前断言模拟器身份，明确无声；未向真机自动导入测试素材。真实声音、设备性能/功耗、实际大库滚动帧率、系统多任务及 Windows 原生宿主本轮 Not Tested。构建/安装不能替代真实媒体验收。
