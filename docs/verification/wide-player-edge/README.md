# 播放视频左侧装饰留白修正

日期：2026-11-06。

用户在 iPad 浅色横向分栏页面看到视频左侧一直有白边。代码确认 PlayerPage 对宽页面保留两侧各 20 逻辑点留白、10 点视频圆角，并居中放置视频；此前 iPad 页面本身已铺满窗口，白边来自视频外侧的页面背景，不是根页面黑框，也不是片源宽高比留黑。

本次只修改视频布局：iPad 与左右分栏模式取消视频外侧装饰留白/圆角，使用左对齐。高度受限而视频宽度缩小时也不再居中产生左侧空白。页面标题、媒体信息、悬浮按钮保留原间距和 SafeArea，16:9 容器及片源 fit 保持，播放器会话、字幕和解码不变。桌面原上下布局继续采用原阅读宽度，超宽桌面的整体内容居中不在本次调整范围。

## 验证

- `./scripts/check`：格式、静态分析、132 项测试通过，见 [检查](check.log)。现有宽屏行为回归增加左侧几何断言，切换、筛选、缩放、状态和选集检查保留。
- iPad iOS 27.2 模拟器原生实验通过，见 [日志](ipad-native.log)、[结果](ipad-observations.json)。浅色/深色、窄屏右侧列表/宽屏原布局均断言视频左边界为 0；分栏视频由约 798×449 变为 838×471，比例保持 16:9。全屏往返、外挂字幕轨道和播放中切换延续通过，选集之前引擎仍只创建一次。
- 原生实验只在断言为模拟器后写入生成素材，明确无声；没有在物理设备导入实验素材。iPad 横向/小窗口仍是 Flutter 视口适配，系统级旋转、分屏、Stage Manager 和真实声音本轮未新增验收。iPhone/桌面本轮没有重跑原生实验，不能据此声称全平台验证。
