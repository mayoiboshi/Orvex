# 首页第一轮像素精修

在现有信息结构上精修 LibraryViews 和共享 LibraryTabBar，继续沿用语义 Token 与 GlassSurface。未改变播放、历史、媒体匹配、数据结构或依赖，也没有恢复复古配色。

## 调整

- 首页标题由较重的大标题收为 24 点中等字重，副标题改为真实视频/可续播数量；搜索与添加合为轻量工具组。
- 主续播卡保留左海报、右信息，海报融入边缘；作品名、集号、元数据、时间和进度分层，进度线 2 点，主操作为胶囊按钮。正常样本卡高约 244 → 196，大字体/长标题仍可随内容增高。
- 续播轨道统一两行标题高度、封面圆角和细进度。最近添加的标题/辅助信息对齐，资料按钮减轻；原视频顺序、每文件展示及点击行为保留。
- 媒体库总入口采用已有封面的小型叠层，保留本地视频/数量/保存位置/进入箭头，没有新增来源或收藏功能。
- 导航实际测量由 560×71 → 500×52，正常尺寸明显减重。去掉选中大底块，用图标、文字和细标记；宽屏图文横排，窄屏/大字体纵排，触控区至少 44×44。
- 内容卡片不做模糊；仅导航沿用局部 Flutter 玻璃，减少透明度时实色回退，保持系统/明暗主题。不是 Apple 原生 Liquid Glass。

## 验证与限制

- `./scripts/check` 通过：格式、静态分析、134 项测试，见 [完整检查](check.log)。最终测试调整后又复核了 [静态分析](analyze-final.log) 和 [有内容的首页测试](populated-test.log)。
- 有内容的首页覆盖 360/834/1210 宽度、明暗主题和 1/2 倍文字；实际点击主卡、续播卡及长按、媒体库、最近添加/资料、顶部搜索/添加和四模块导航，检查目标身份和回调，同时断言导航目标至少 44×44。没有删除测试；旧空状态断言随新文案更新。
- iPad iOS 27.2 模拟器 before / after 两次独立运行通过，见 [修改前日志](before.log)、[修改后日志](after.log)、[前指标](before-observations.json)、[后指标](after-observations.json)。1210×834、834×1210 为 Flutter 视口适配，不等于系统级旋转、Split View 或 Stage Manager。
- after 真实打开搜索页、播放记录、媒体库，并从主卡打开原生 libmpv，确认正确视频从原进度续播；添加入口验证调用文件适配器并取消，没有操纵系统文件选择器。减少透明度后页面没有 BackdropFilter。
- 观看数据/元数据与偏好在实验中隔离，未测试真实存储跨重启。本次使用已有封面缓存，Bangumi 联网准确性不属于新增验收。
- 模拟器写入生成素材前断言设备身份，明确无声；没有在物理设备导入实验素材。真机视觉、声音、性能、大片库滚动帧率、系统多任务和其他原生宿主本轮 Not Tested；iPhone 安装按用户要求暂停。
- 初轮新测试曾因缺少内存偏好初始化、页面滚动恢复后点击离屏记录入口失败；补齐测试环境，并将截图/点击准备改为明确回顶及使目标处于可见区，保留真实跳转和续播断言，未修改产品路由来规避失败。

## 下一轮建议

优先以真实片库验收分屏下的长标题与最近添加密度。同剧集的多个视频仍沿用现有逐文件数据和相同海报；若要按剧集合并展示，应作为后续明确需求评估，不能为了截图好看改变当前业务规则。
