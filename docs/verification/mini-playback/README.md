# 底部悬浮播放卡

共享播放卡复用现有播放会话和本地预览缓存。播放或暂停不展开播放器，展开不重新打开文件。标题按当前文件已关联的作品和本地集号显示，缺少关联时显示原始文件名。进度与状态由现有播放帧提供。

播放卡和底部导航由同一个底部区域测量。作品、文件夹、播放记录和设置的滚动底部使用实际测量后的安全区，完整播放页内的剧集列表保留原有间距。

`./scripts/check` 通过格式、静态分析和 157 项测试。组件测试验证文件夹子目录、有无卡片时的末行、放大文字、原始长文件名、播放记录页和导航位置。iPad 模拟器使用无声测试素材，确认缓存预览、同一原生会话暂停和继续、展开时位置不变，以及点击末行的资料按钮和从末行开播。实际用户文件、真机声音与桌面侧栏未做交互验收。
