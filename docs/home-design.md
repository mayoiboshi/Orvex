# iOS / iPadOS 首页第一版

当前只推进 iOS 和 iPadOS。参考 [Infuse 的首页内容分区](https://firecore.com/blog/infuse-84-extras-intros-and-favorites)，使用 Orvex 自己的图形、配色和布局，不引入其他产品素材。

底部固定四个模块：**首页、媒体库、播放记录、设置**。深色背景搭配暖金色操作色；iPad 扩大内容宽度和封面列数，保留同样的底部导航。

| 模块 | 当前可用行为 |
| --- | --- |
| 首页 | 导入或继续播放主卡、继续观看进度卡、本地视频入口、最近添加 |
| 媒体库 | 已导入文件的封面网格、名称搜索、点击播放 |
| 播放记录 | 最近 100 部视频、观看进度、点击重开、完成状态；保存到本机 |
| 设置 | 显示继续观看开关并持久保存、导入入口、字幕和进度说明、版本及开源许可 |

内容均来自实际导入和实际播放。没有海报时使用原创抽象图形，不填充虚构片名或观看数据。旧版视频和恢复进度继续保留；新播放产生的记录进入新首页。字幕选择仍未跨播放会话恢复。

验证：25 项测试通过，覆盖四模块切换、搜索到播放、返回浏览后的真实记录、记录去重及持久化；静态分析通过。iPhone 模拟器原生回归通过，并生成四模块截图；iPad 模拟器已检查首页预览。布局测试覆盖 360、430、744、1194 宽度。

模拟器播放仍使用明确标记的无声预览。iPad 真机、新首页真机交互和长期性能为 **Not Tested**；此前 iPhone 用户自备媒体通过的核心播放验收记录独立保留。截图和日志见 `verification/home-stage1/`。

本文保留首页第一版设计及当时验证范围；后续功能和当前完成度见 [ROADMAP](ROADMAP.md)，不在此重复维护能力清单。
